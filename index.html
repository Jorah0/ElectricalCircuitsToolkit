Ask about the circuit on the canvas, or describe one to generate (“design a 1 kHz band-pass filter for a 5 V sine source”). The assistant sees the netlist, the insights and your latest results, and can build circuits and run analyses itself.

AI connection

The key goes only from this browser to api.anthropic.com. A remembered key is stored in this browser profile’s local storage, where anything else running on this page’s address could read it.

Netlist

One part per line: NAME node+ node− value. Node 0 (or gnd) is ground; named nodes become trace labels. Sources: DC 5 · SIN(offset amp freq 0 0 phase) · SQUARE/TRI/SAW(offset amp freq) · STEP(amp) · EXPR 5*sin(2*pi*t).
